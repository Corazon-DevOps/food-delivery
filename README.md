# Food Delivery — Expo Premium UI

Protótipo visual interativo em React Native + Expo + TypeScript inspirado na referência enviada pelo usuário.

## Executar

```bash
npm install
npx expo install --fix
npx expo start -c
```

Abra o QR code no Expo Go compatível com Expo SDK 58.

## Incluído nesta primeira versão

- Home com categorias, campo de pesquisa, banner, cards e navegação inferior.
- Detalhes com foto principal, tamanho, adicionais, quantidade e botão de carrinho.
- Favoritos e carrinho local, sem backend ou checkout.

**Observação:** Imagens remotas temporárias da Unsplash. A substituição por imagens licenciadas com o mesmo recorte e iluminação da referência é necessária para chegar à fidelidade visual desejada. O aplicativo ainda precisa ser testado em dispositivo físico.
